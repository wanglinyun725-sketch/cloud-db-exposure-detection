# 中期汇报承诺对账与后续研究路线

## 总判断

中期汇报的方向不需要推翻，但必须重新定义“Agent 主动发现证据链路”：

> Agent 不是在完整风险图上调用大模型给所有路径打分，而是在部分可观测条件下，
> 交替执行候选扩展、证据查询、状态更新和停止判断，最终输出可复核的有效路径
> 证书或否定证书。

原实现的问题不是没有 Agent 流程图，而是查询前已经能读取完整的
`status/time/strength`，离线降级还会一次性调用所有工具。`query_cost` 只是排序
扣分，没有改变“下一步查什么”和“何时停止”，因此不能支持主动调查主张。

本轮已经完成第一步实质整改：

- 新增部分可观测证据环境，查询前隐藏状态、强度、置信度、时间与原始证据；
- 每次动作只查询一条边，并真实消耗预算；
- 支持全量、固定顺序、随机、Coverage/Cost 和 VOI/Cost 五种策略；
- 只有形成有效路径证书、否定证书或预算耗尽时才能停止；
- blocker 先验只在 validation 上估计，test/hard_test 不参与拟合；
- 新增 held-out 预算—正确性实验和以独立 group 为单位的统计检验。

## 新的论文主线

建议把论文从“大模型 Agent 自动发现攻击链”收缩为下面三个可验证问题：

### RQ1：如何生成结构合法、边身份明确的暴露路径假设？

使用类型化多重风险图和 edge-aware 路径表示：

\[
P=(V_P,E_P),\qquad
E_P=(e_1,\ldots,e_m),\quad e_i=(u_i,v_i,\tau_i,\mathrm{id}_i).
\]

边 ID 是路径定义的一部分，避免同一节点对上的权限边、审计边等被混为一条链。

### RQ2：证据不可见且预算有限时，Agent 应先查什么？

时刻 \(t\) 的调查状态定义为：

\[
b_t=(\mathcal F_t,\mathcal O_t,\mathcal U_t,B_t),
\]

其中 \(\mathcal F_t\) 是仍可行的候选前沿，\(\mathcal O_t\) 是已观察证据，
\(\mathcal U_t\) 是未查询项，\(B_t\) 是剩余预算。动作 \(a_t=q(e)\) 查询一条边，
环境返回支持、反证或缺证状态及原始证据引用。

第一版 VOI/Cost 策略为：

\[
a_t^*=\arg\max_{e\in\mathcal U_t}
\frac{
\hat p_{\mathrm{block}}(\tau_e)N_{\mathrm{prune}}(e)
+[1-\hat p_{\mathrm{block}}(\tau_e)]N_{\mathrm{complete}}(e)
}{c(e)}.
\]

这条公式的每一项都有代码、数据或动作轨迹对应，不是为了显得复杂而拼接权重。

### RQ3：Agent 何时可以停止，并如何保证结论可复核？

有效路径证书：

\[
\mathcal C^+(P)=\{e\in E_P:\operatorname{state}(e)=T\},
\]

要求路径所有硬条件均获得支持且不存在时间冲突。

否定证书：

\[
\mathcal C^-=\{e_P\mid
\forall P\in\mathcal F_0,\ e_P\in E_P,\ 
\operatorname{state}(e_P)\in\{F,U\}\}.
\]

即每条候选至少有一个已查询的反证或确定缺证。预算耗尽但证书不完整时必须
输出 `abstain`，不能强行给结论。

路径真实性与严重度必须分离：

1. T/F/U 状态传播和证书判定路径是否成立；
2. Gate·Score 只对已经成立的路径做风险严重度排序；
3. LLM 只负责候选优先级、工具参数生成和自然语言表达，不能覆盖确定性证据状态。

## 第一轮真实实验结论

评估使用 test + hard_test 的 97 个可搜索样本，来自 28 个独立 group；
26 个候选池存在有效路径，71 个不存在。所有策略使用相同结构候选和查询成本。

| 策略 | 满预算决策正确率 | 平均查询成本 | 平均工具调用 |
|---|---:|---:|---:|
| 全量查询 | 100% | 9.732 | 7.505 |
| 固定顺序 | 100% | 3.258 | 2.773 |
| Coverage/Cost | 100% | 4.309 | 3.907 |
| validation VOI/Cost | 100% | 3.196 | 2.742 |
| 随机顺序 | 100% | 5.485 | 3.856 |

组级配对置换检验：

- VOI/Cost 相对全量查询的成本差为 -6.6786，p=0.00002；
- VOI/Cost 相对固定顺序的成本差为 -0.0536，p=0.52279，不显著；
- Coverage/Cost 相对固定顺序反而增加 1.1250，p=0.00002。

因此可支持：

- 部分可观测主动查询在保持满预算停止正确性的同时，显著少于全量取证；
- VOI/Cost 能形成可运行的验证集拟合策略和审计轨迹。

目前不能支持：

- VOI/Cost 已显著优于固定顺序；
- 当前主动策略具有跨来源的普遍最优性；
- 100% 停止正确率等同于真实环境检测准确率。该数字来自同一确定性规则定义下的
  内部闭环验证。

## 接下来按这个顺序继续

### P0：完成“主动调查”算法闭环（当前已完成第一版）

- 部分可观测环境；
- 逐步查询和预算；
- 有效/否定证书；
- 强基线与预算曲线；
- validation/test 隔离。

### P1：把单一策略升级为召回—成本 Pareto 搜索

下一轮不继续手调一个综合权重，而是同时维护：

\[
J(P)=
\bigl(
\text{unresolved hard evidence},
\text{expected pruning},
\text{query cost},
\text{path length}
\bigr).
\]

只有在所有目标上都不优于另一候选时才被支配剪枝。实验主图应画：

- x 轴：平均查询成本；
- y 轴：valid discovery recall；
- 辅助指标：correct rejection、abstention、证书大小；
- 分来源报告 pathbench_60、samples_v2 和外部人工集。

### P2：建立真正独立的人工外部测试集

这是能否达到“优秀毕业设计”的最大瓶颈，优先级高于增加模型微调：

- 至少 30–50 个独立案例，不使用同图 missing/refuted 变体充数；
- 两名标注者独立标出 edge-aware 路径、证据状态和最小证书；
- 报告一致性与仲裁过程；
- 策略和阈值冻结后只运行一次 external test。

### P3：接入真实工具适配器

当前逐边 query 是可复现实验环境。下一步把相同接口映射到：

- 网络连通/安全组查询；
- IAM 与数据库授权解析；
- Schema 与敏感标签查询；
- 审计日志和控制项查询。

真实适配器仍返回统一 `T/F/U + source + time + raw_evidence + cost`，算法层无需
因工具变化重写。

### P4：模型对齐只作为可选项

只有在 P1–P3 完成且仍有时间时，才考虑让 LLM 学习动作排序。训练目标应是模仿
Pareto/VOI 策略或降低无效调用，而不是让模型替代证据验证。若没有独立训练和
测试结果，GV-FA、SFT、DPO 全部保留为未来工作。

## 最终答辩叙事

建议使用下面这句作为统一口径：

> 本研究并不让大模型直接判断高敏数据是否暴露，而是把 Agent 建模为部分可观测
> 风险图上的预算约束调查者。Agent 主动选择下一项证据查询，确定性验证器维护
> T/F/U 状态并生成最小证书，Gate·Score 再对已验证路径进行严重度排序。

这比“LLM 自动发现攻击链”更收敛，但更真实、可复现，也更容易经受评委追问。
