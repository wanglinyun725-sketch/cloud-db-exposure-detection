## 结论先行

项目已经能够在本地离线完整运行，核心代码、数据校验、主实验、统计检验和
Web demo 均已打通。作为工程型硕士毕业设计，它已经形成了较完整的研究原型，
具备通过和争取“良好”的基础。

但按较严格的“优秀研究生毕业设计”标准，当前版本还不能客观认定为优秀。
核心原因不是系统不能运行，而是外部有效性、数据独立性和组件贡献证据仍不足。
第二阶段已修复 edge-aware 路径和 SDDP 受控证据契约，综合评分更新为
**7.1/10**；若完成本文列出的剩余 P0 整改，
项目有机会达到优秀水平。

本评价只针对当前仓库与可复现实验，不替代学校、学院和评审专家的正式标准。

## 数据与实验事实

### 数据构成

| 指标 | 数值 |
|---|---:|
| 总样本 | 308 |
| 独立样本组 | 104 |
| 基础样本 | 104 |
| 受控衍生变体 | 204（66.23%） |
| 路径标签 | 672 |
| test + hard_test 检索样本 | 23 |
| CloudGoat 检索 gold path | 0 |

随机划分按 group 完成，同一基础样本的变体不会跨 split，这是正确做法。但有效
独立单元只有 104 组，且最终统计检验只有 23 个带 Valid gold path 的留出样本，
统计功效和覆盖面仍有限。

### 统一参数后的内部 held-out 结果

RefuteAwareBeamSearch 固定使用生产默认 `beam_width=4`。

| split | Full-constrained R@3 | RefuteAware R@3 |
|---|---:|---:|
| test（n=13） | 0.2000 | 0.6923 |
| hard_test（n=10） | 0.2200 | 0.6600 |
| 合并（n=23） | 0.2087 | 0.6783 |

在合并的 23 个配对样本上：

| 指标 | 均值差 | Cohen's dz | Holm p | 结论 |
|---|---:|---:|---:|---|
| R@1 | +0.0783 | 0.2085 | 0.9351 | 不显著 |
| R@3 | +0.4696 | 0.8180 | 0.0068 | 显著 |
| R@5 | +0.3565 | 0.6646 | 0.0154 | 显著 |
| MRR | +0.1141 | 0.2192 | 0.9351 | 不显著 |
| P@3 | +0.0724 | 0.2313 | 0.9351 | 不显著 |

因此，当前实验可以支持“内部构造语料上 Top-3/Top-5 召回更高”，不能支持
“所有检索指标全面显著提升”或“已证明跨场景泛化”。

### 来源分层后出现结论反转

| 来源 | n | Full R@3 | RefuteAware R@3 | Full MRR | RefuteAware MRR |
|---|---:|---:|---:|---:|---:|
| pathbench_60 | 14 | 0.1429 | 1.0000 | 0.1964 | 0.6786 |
| samples_v2 | 9 | 0.3111 | 0.1778 | 0.7659 | 0.3075 |

聚合提升主要来自 `pathbench_60`；在 `samples_v2` 上，RefuteAwareBeamSearch
反而弱于完整约束基线。这说明当前方法对数据来源和图结构高度敏感，是判断
是否达到“优秀”的关键负面证据。

进一步的 50,000 次来源标签置换检验表明，五项指标的方法增益均存在校正后
显著的来源异质性：R@3 与 MRR 的 Holm p 均约为 0.0001，R@5 为 0.0023，
R@1 为 0.0182，P@3 为 0.0004。因此来源反转不能简单解释为普通抽样波动；
当前聚合优势具有明显的 source-specific 特征。

### 简单基线与外部切片

在同一 23 个样本上，edge-aware 随机排序 1,000 次的平均 R@3 为 0.3315、
R@5 为 0.5192、MRR 为 0.4630。RefuteAware 的 R@3 明显更高，但 MRR
优势仍不大。

修正后的 SDDP 受控切片包含 8 条 edge-aware gold path：

- 当前生产检索器命中 8/8；
- 验证器状态与期望一致 8/8；
- base 扫描接入不再标为攻击路径；只有显式注入外部主体、连通和权限的
  controlled case 才作为暴露假设。

这证明了 SDDP 格式、搜索器和验证器在受控假设下契约一致，仍不能表述为
“真实攻击检测准确率 100%”。

## 关键技术风险

### 1. 并行边歧义（已整改）

路径现已同时保存节点、`edge_ids` 和 `edge_types`；搜索、验证、查询成本和
指标匹配均引用实际经过的边。104 个基础样本共有 180 条标注路径，其中 72 条
（40%）经过多类型并行边；这 180 条标签现已全部具备完整 edge 引用，
受影响但仍为 node-only 的标签数为 0。

### 2. SDDP 语义契约（已整改，仍属受控验证）

生成器现会显式建模受控外部主体、网络连通、数据库权限、证据时间和敏感对象，
并对 base 扫描证据采用保守的 Insufficient/no-gold 定义。8 条受控 gold 当前
全部可检索且状态一致。剩余问题是这些路径仍由可控假设生成，不是独立人工
标注的真实攻击 ground truth。

### 3. 参数与测试独立性不够严格

当前统一选择 `beam_width=4`，但该参数最初参考过 all-corpus 开发结果，因此
现有 test 不能视为完全未触碰的最终测试集。正确流程应在 validation 冻结参数，
再建立新的独立 test 或 external_test。

### 4. 消融尚未证明核心组件贡献

最新 all-corpus 消融中，移除 refute scoring 或 temporal 后结果完全相同；
移除 query cost 后 R@3、R@5 和 MRR 还略有提高。目前更能确认的是 beam 搜索
策略有效，尚不能确认“反证感知”“时间语义”“查询代价”带来独立质量增益。

### 5. 创新主张需要与实现对齐

C1 证据语义化、T/F/U 验证和 C2 启发式 Beam 搜索已实现；C3、SFT、DPO 等仅有
接口设想，不能作为已完成实验贡献。若论文仍包含 GV-FA 或模型训练类主张，
应实现并实验验证，或从核心贡献中删除。

## 要达到“优秀”的 P0 整改

1. **建立真正独立的外部测试集**：建议至少 30–50 个独立、人工标注案例，
   不用同图受控变体充数；CloudGoat 若保留为基准，应补充可审计的 gold。
2. **解决已确认的来源依赖**：当前来源异质性在五项指标上均显著。应定位
   `samples_v2` 失败模式、调整方法，并用新的来源或 source-held-out 重验。
3. **冻结实验协议**：只用 validation 选参数，建立未参与任何调参的新 test，
   提前固定主指标、基线和统计方法。
4. **补强基线与消融**：增加标准 k-shortest path 等可解释基线；构造能区分
   refute、temporal、query cost 的独立测试，或收缩这些组件的创新主张。
5. **收缩或兑现论文主张**：只把已实现且有实验支持的 C1/C2 写成贡献；
   未实现的训练模块放入未来工作。

## 最终判断

- **作为硕士工程型毕业设计**：当前是一个较完整、可运行、有一定方法设计的项目。
- **作为“优秀”研究生毕业设计**：当前证据不足，不建议在论文或答辩材料中直接
  宣称已经达到优秀。
- **最有价值的下一步**：建立独立人工标注的外部测试集并解决来源依赖；
  这对最终评级的提升远大于继续美化 demo 或增加更多同源变体。
