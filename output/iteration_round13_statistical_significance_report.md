# 第十三轮迭代报告：样本级统计检验修正

## 修正原因

旧版统计脚本从单个聚合均值人为生成高斯噪声，再据此计算置信区间和
t 检验。这些伪样本不是真实实验观测，因此旧版 p 值和效应量不能用于论文。

本轮已将统计流程改为：

1. 在每种检索方法的输出中保存真实样本级指标。
2. 只使用 `dataset_v1` 的 `test` 与 `hard_test`。
3. 对同一个样本上的基线和 RefuteAwareBeamSearch 指标做配对比较。
4. 使用 10,000 次非参数 percentile bootstrap 计算 95% CI。
5. 使用 50,000 次双侧配对符号翻转置换检验。
6. 对每组五项指标使用 Holm-Bonferroni 校正。

## RefuteAwareBeamSearch 的 held-out 指标

test 与 hard_test 共提供 23 个带 Valid gold path 的配对检索样本。

| 指标 | 均值 | 95% CI |
|---|---:|---:|
| R@1 | 0.2174 | [0.0435, 0.3913] |
| R@3 | 0.6783 | [0.5043, 0.8435] |
| R@5 | 0.7217 | [0.5652, 0.8696] |
| MRR | 0.5334 | [0.4257, 0.6504] |
| P@3 | 0.3188 | [0.2608, 0.3768] |

## 与 Full-constrained DFS + GateScore 的配对比较

## 当前可写入论文的结论

在 23 个 held-out 配对检索样本上，RefuteAwareBeamSearch 显著提升了
R@3（均值差 +0.4696，Holm 校正后 p=0.0068，Cohen's dz=0.8180）
和 R@5（均值差 +0.3565，Holm 校正后 p=0.0154，Cohen's dz=0.6646）。
R@1、MRR 和 P@3 的样本均值虽有提升，但在当前样本规模下未达到
校正后的显著性阈值。

因此应删除“4/5 指标显著”“p=0.001”以及“所有指标均大效应量”等旧结论。
当前结果支持的是 Top-3/Top-5 召回优势，而不是所有检索指标的全面显著提升。

注意：23 个检索样本仍然很少，且按来源分层后性能方向不一致，因此这些
显著性结果只能视为当前构造语料上的内部证据，不能替代外部测试集验证。
