# 第七章 结论、局限与复现

## 7.1 当前可成立的结论

本文已经建立三个可检查的研究部件：第一，覆盖 AWS、Azure、GCP 的真实来源
候选库存及来源追溯协议；第二，具有 ReAct、Tool Use、作用域守卫、四值记忆、
Pareto 动作选择和硬预算的 EC-ReAct 实现；第三，与 LLM 解耦的 CP-Cert
最小证书和独立审计器。工程测试证明这些部件能够按照定义运行。

但在双人 gold 和冻结主实验完成前，本文只能陈述“基准与方法实现完成、研究
效果待验证”。最终结论由
`output/ec_react_main_v2/confirmatory_decision.json` 决定，而不是由作者
主观选择最好看的表格决定。

## 7.2 主要局限

### 7.2.1 来源真实性不等于生产代表性

候选材料来自公开研究数据、攻击模拟和云靶场，具有可追溯性，但受控环境中的
噪声、身份结构和业务复杂度低于企业生产云。最终结论应限定为“在所覆盖公开
来源和固定工具视图上”，不能外推为所有真实企业环境。

### 7.2.2 确认性运行来源少于完整候选来源

完整库存有 9 个上游来源，而当前确认性运行时包只有 4 个证据来源。配置仓库
增加了场景广度，但不能替代运行时 held-out 验证。

### 7.2.3 样本量可能欠功效

30 个双标目标足以运行预注册主实验，但低于检测中小效应所需规模。最终必须
报告不确定性，不把未显著解释为没有差异，也不把单个显著 p 值解释为充分证据。

### 7.2.4 外部规则先验存在平台偏差

Sigma 操作覆盖在平台间不均衡。该先验只参与动作优先级，不参与最终判定，并
通过独立消融和分平台切片检查其净效应。

### 7.2.5 证书正确不等于语义正确

CP-Cert 证明候选路径被当前可见证据充分覆盖，但若 ontology 映射、路径边界或
人工语义不同，证书路径仍可能是语义误报。必须同时报告“证书有效但不匹配 gold”
的比例。

### 7.2.6 模型和云服务会变化

本地模型用 runtime digest 锁定，强模型使用日期快照。即便如此，远程服务的
基础设施和工具 SDK 仍可能变化，因此复现包保存完整提示词、工具 schema、
运行 JSONL、版本和哈希，而不只保存模型名称。

## 7.3 可复现链

统一流水线按以下顺序失败关闭：

1. 冻结双人确认 gold；
2. 冻结外部负对照；
3. plan-only preflight 与显式 schedule；
4. 绑定输入、代码和模型的 FROZEN 配置；
5. 两模型主实验与断点续跑；
6. 谱系级统计分析；
7. 预注册机器结论；
8. 确定性 reproduction ZIP；
9. 方法、统计、云安全三轮独立压力测试；
10. 论文、答辩和复现包最终哈希清单。

核心命令为：

```powershell
D:\anaconda\python.exe scripts/experiments/run_research_pipeline_v2.py
D:\anaconda\python.exe scripts/experiments/freeze_ec_react_protocol_v2.py
D:\anaconda\python.exe scripts/experiments/run_research_pipeline_v2.py `
  --mode execute `
  --config configs/ec_react_main_v2_frozen.yaml
D:\anaconda\python.exe scripts/experiments/package_reproduction_v2.py
D:\anaconda\python.exe scripts/experiments/audit_goal_acceptance_v2.py
```

分析与结论文件保存完整 SHA-256 链；复现 ZIP 从冻结 manifest 指定的 Git
commit 读取代码，加入冻结输入、运行记录、分析和决策，固定文件顺序与时间戳。
密钥不进入 manifest 或压缩包。

## 7.4 创新点的最终判定规则

- **C1**：只有双人 gold、仲裁、一致性和来源隔离全部完成，才称“真实跨云
  证据路径基准”已验收；
- **C2**：只有两个模型均达到 exact edge F1 与相对收益门槛，且错误
  Reachable 不增加，才称 EC-ReAct 方法有效；
- **C3**：只有证书消融满足预注册路径质量与 unsupported-path 条件，才升级为
  独立第三创新；否则降级为安全机制。

如果 C2 或 C3 未过线，论文保留负结果、失败切片和边界条件，不更换指标或删除
失败运行。

## 7.5 展望

在完成当前冻结实验后，可进一步扩展到真实企业混合业务噪声、跨账号与跨云身份
联邦、网络流量和宿主机行为等多源证据；在方法上可研究学习型动作价值估计，但
必须继续由作用域守卫和确定性证书约束；在数据治理上可扩大独立谱系至功效分析
建议规模，并引入机构外部专家复核。

## 7.6 本章小结

本研究的价值不在于给 Agent 添加更多模块名称，而在于建立从真实来源、人工
gold、预算化探查、确定性证书、谱系级统计到最终交付物的完整证据链。只有该链
全部闭合时，项目才具备优秀研究生毕业设计所要求的可信度。
