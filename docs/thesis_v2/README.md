# Cloud DB PathBench 学位论文 v2

本目录是 Graduate Goal v2 的论文权威工作区。旧目录
`docs/thesis_src/thesis_src/` 保留中期阶段材料，只能用于追溯，不再作为最终
方法、数据规模或实验结果的证据来源。

## 写作原则

1. 真实来源、代码实现、人工标注、工程验证和研究效果必须分开陈述。
2. `human gold = 0` 时不得报告路径发现准确率，也不得把测试夹具或 smoke
   policy 结果写成论文主实验。
3. C1“真实跨云证据路径基准”与 C2“预算约束、作用域感知的 EC-ReAct”是
   必须验收的两个创新点；C3“CP-Cert”只有通过预注册消融后才升级为独立创新。
4. LangGraph 是可替换的编排实现，不作为创新点。
5. 所有数字必须能定位到仓库中的 JSON、冻结 manifest 或最终分析输出。

## 文件结构

- `00_摘要与主张边界.md`：最终摘要骨架和贡献口径；
- `03_真实跨云证据路径基准.md`：数据来源、去重、标注与冻结协议；
- `04_预算约束的作用域感知EC-ReAct.md`：核心方法和公式；
- `05_CP-Cert确定性路径证书.md`：条件性第三创新与算法边界；
- `06_冻结实验设计与结果.md`：预注册实验、统计方法和结果占位；
- `07_结论局限与复现.md`：结论规则、威胁与交付；
- `claim_evidence_matrix.md`：逐项主张—证据验收表。
