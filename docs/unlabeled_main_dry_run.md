# 无标签主条件干跑审计

## 目的

在不读取人工 gold、不调用 LLM、也不计算路径正确率的前提下，对冻结主配置中的非 LLM 方法做全实例执行审计。该审计只回答：

- 所有保留的真实运行实例能否被统一工具环境执行；
- 固定顺序、完整查询和随机工具基线能否在各预算下完成；
- 硬预算是否始终生效；
- 线性执行后端与 LangGraph 后端是否语义一致；
- 结果是否可由固定配置、数据哈希和随机种子复现。

它不回答任何方法是否优于基线的问题。

## 冻结矩阵

数据为 v0.5 中全部 91 个非空真实运行实例。每个实例运行：

| 方法 | 预算 | 每个实例重复数 | 总运行数 |
|---|---|---:|---:|
| `fixed_order` | 10、20、30 | 1 | 273 |
| `full_query` | 10、20、30 | 1 | 273 |
| `random_tool` | 10、20、30 | 5 | 1,365 |
| 合计 |  |  | 1,911 |

每次运行都分别经过线性后端和 LangGraph 后端，随后比较规范化结果。

## 当前结果

| 审计项 | 结果 |
|---|---:|
| 真实运行实例 | 91 |
| 计划运行 | 1,911 |
| 完成运行 | 1,911 |
| 执行失败 | 0 |
| 硬预算违规 | 0 |
| 线性/LangGraph 不一致 | 0 |
| `research_effectiveness_result` | `false` |

输出文件为 `output/unlabeled_main_dry_run.json`，其中记录了配置和数据包 SHA-256、逐次运行种子、停止原因、预算消耗及后端一致性。

## 论文中的合法表述

可以写：

> 在 91 个真实运行实例、1,911 个冻结非 LLM 条件上完成执行审计，未发现执行失败、硬预算违规或编排后端语义不一致。

不可以写：

> 系统发现了 1,566 条正确路径，或 EC-ReAct 的准确率已经得到验证。

输出中的 `evidence_certified_paths` 仅代表路径候选通过内部证据证书规则。只有与双人独立标注并经裁决冻结的外部 gold 对照后，才能计算 precision、recall、F1、成功率或方法间显著性。
